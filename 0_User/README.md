# 0_User

Who you are and how you work. Your agent reads this to adapt to you. Company facts go in `0_Company/` instead.

Everything here except this README is gitignored. The folder starts empty, and `onboarding` fills it in.

| File | Holds |
|---|---|
| `01_Overview.md` | Name, role, company, one-line identity |
| `02_Expertise.md` | Background, domain knowledge, strengths and gaps |
| `03_Preferences.md` | Tone, depth, pace, how you make decisions, tools you use |
| `04_Goals.md` | What you're trying to achieve now and longer term |
| `05_Voice.md` | How you write, built from your past emails |
| `Z_Library.md` | Fuller background, referred to by section |

Keep each file short and skimmable. Longer detail goes in `Z_Library.md`.

The agent changes these files through the `util-user-info` skill. You can also edit them yourself at any time.
