# 1_Work_Projects

One-off dated projects. These can be shared with a team.

Name each folder `YYYY.MM.DD <Name>`, or `YYYY.MM <Name>` for month-long work.

```
1_Work_Projects/
└── 2026.11.06 Outreach/
    ├── README.md      goal, status, next steps
    └── ...            whatever the project produces
```

The `util-files` skill creates new project folders. When a process is settled, `util-files` promotes it to
`3_Library/`. The project stays as the record of how it was built.

**Private projects:** if a project will hold contacts, add its path to `.gitignore` before saving anything in it, so
it can't reach a repo by accident.
