# Send it

The user sends one email from their own mailbox. You never send.

## When the user types "sent"

Use this only when Send it is the active step, or when you're already guiding Send it after Make it yours
finished. Otherwise treat "sent" like any other out-of-step message: say which step you're on.

1. **No draft saved.** If First drafts or the last Make it yours rerun wrote no files under `drafts/`, say so. Go back
   to Make it yours. Do not enter Send it or ask for "sent" until there is at least one draft.

2. **One draft.** Add `YYYY-MM-DD sent <Contact>` to today's memory log, then go to What's next.

3. **More than one draft.** Ask which contact they sent to. Then add the log line for that contact, then go to What's
   next.

Say, in Send it: "Send one now, from your own email. I never send."

**Writes:** today's memory log only. Never a mailbox.
