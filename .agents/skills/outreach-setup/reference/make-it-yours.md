# Make it yours

The user types `not yet: <what's wrong>` or `good enough`.

Length lives only in `## Drafts` in the settings file. Do not send length feedback to `0_User/05_Voice.md`. Use
`## Drafts` for word limits; use the voice file for tone and phrases only.

## First time here

When the user reaches Make it yours after First drafts, show the drafts and ask "Good enough?" before you critique
or suggest changes.

## On not yet

1. Put the feedback in the right file:

   | What's wrong | Where it goes |
   |---|---|
   | Tone and phrases | `0_User/05_Voice.md`, with `util-user-info` |
   | The ask, the reasons and the sources | the settings file, edited in this step |
   | A skipped step | the skill, with `make-skill` |

2. Show the change. Rerun only the contacts that got no draft, plus any the user names. Remove the named ones' rows
   from `sleep-log.md`, so the run doesn't skip them. The user types: "run outreach again on <Name>, <Name>"
3. Show the old and new drafts side by side. Ask "Good enough?" again.

## On good enough

If `drafts/` has no files, say so and stay here. Otherwise go to Send it.
