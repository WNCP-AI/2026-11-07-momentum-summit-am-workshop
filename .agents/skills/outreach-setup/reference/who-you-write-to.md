# Who you write to

The user types "investor outreach", "sales outreach" or "both". Then: "Goal: <one sentence on what these emails are for this quarter>".

1. If onboarding already saved a mode, confirm it instead of asking. Write it in `## Mode`.
2. Write one or two sentences per mode in `## Goal`. Use the user's words.
3. Make the reason and draft rules theirs: fill every `<...>` from `0_Company/`, delete the `###` subsections for a mode they didn't pick, and show the user both sections. Delete the opening "The lines below are an example" note.

**Writes:** `## Mode`, `## Goal`, `## What counts as a reason` and `## Drafts` in the settings file.
